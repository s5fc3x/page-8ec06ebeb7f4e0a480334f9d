光速云 · gscloud · 订阅指南

光速云(gscloud) · 先看明白,再决定要不要订阅。一份写给普通用户的网络套餐清单。

光速云 gscloud 提供从基础到团队的三档网络订阅,主打量级流量、多设备同开与按场景路由。本文用问答的方式,把套餐权益、设备数、流量节奏和上手步骤一次性整理出来,省去翻聊天记录的麻烦。

光速云把订阅分成个人轻度、深度玩家、小型团队三档,差异落在月流量、同时在线设备数与可用节点类型上。

面向流媒体观看与日常浏览,可从基础版起步;对游戏延迟敏感或需要在多屏之间切换,旗舰版的原生流媒体与 IPLC 专线更贴合;而需要稳定高带宽并希望得到专属接待的,团队版接入企业路由与客户经理服务。

从下单到连上,大致走这四步

USAGE FLOW · 02

如果以前用过类似的网络工具,流程基本一致;不同的地方在于订阅与节点是分开管理的,套餐下单之后会拿到一串订阅地址。

STEP 01 01

选一档适合自己的方案

先评估家里或工作室一共有多少台设备同时上网,再估算一个月大约会用掉多少流量。基础版每月 100GB 给轻度浏览和偶尔看视频足够;旗舰版的 300GB 更适合经常看剧或游戏联机;团队版 1000GB 主要给多人共用。

  • 看月流量,不只看单月价格
  • 按同时在线设备数挑档
  • 对延迟敏感认准 IPLC 专线
STEP 02 02

完成付款并记下订阅链接

下单后,后台会生成一条以 http 或 https 开头的订阅地址,通常称作订阅链接。这条链接里包含你的账号、节点信息与到期日,后续导入客户端全靠它。建议把链接复制到自己的备忘录,而不是只依赖后台页面。

  • 订阅链接请勿外发
  • 更换套餐后链接会自动更新
  • 到期前可在后台手动续费
STEP 03 03

下载对应平台的客户端

光速云的订阅可以搭配多种第三方客户端使用,具体选择取决于操作系统。本页下方列出了常见桌面与移动端的导入步骤;建议同时在主力设备和备用设备上各装一份,以便切换。

  • 桌面端优先选 v2rayN / Clash Verge
  • 移动端常用 Shadowrocket / v2rayNG
  • 客户端版本尽量保持最新
STEP 04 04

导入订阅并按场景选节点

把订阅链接粘贴到客户端的“订阅设置”或“Profiles”项,触发一次更新,即可看到当前可用节点列表。日常浏览选普通节点即可;看流媒体挑带流媒体标签的;游戏联机或远程办公则进入 IPLC 专线组。

  • 导入后等列表刷新完成
  • 首次使用建议测速一次
  • 遇到连不上先切换节点

客户端要怎么导入订阅?

CLIENTS · 04

以下步骤给出常见操作系统下的通用做法。具体菜单名称会随客户端版本变化,但大逻辑一致:安装 → 粘贴订阅 → 更新 → 选节点。

DESKTOP · WINDOWS / MACOS

桌面端:Clash 系列

以 Clash Verge 或同类 GUI 客户端为例,把订阅链接作为远程配置导入,刷新后即可看到节点分组。

  1. 下载客户端并完成解压安装
  2. 打开 Profiles / 配置 一栏
  3. 选择“从 URL 导入”,粘贴订阅链接
  4. 点击立即更新,等待节点加载
  5. 在 Proxies 选项卡里挑节点启用
下载说明
MOBILE · IOS / ANDROID

移动端:Shadowrocket / v2rayNG

iOS 上常用 Shadowrocket,安卓上常用 v2rayNG。两者都支持一键粘贴订阅,更新后自动列出节点。

  1. 在应用商店或官网获取客户端
  2. 进入 “订阅” 或 “Subscriptions”
  3. 点击 + 号,粘贴订阅链接
  4. 完成更新,在主界面选择节点
  5. 打开连接开关,确认图标变色
下载说明
CLI · LINUX / NAS

命令行与旁路由场景

如果跑在 OpenWrt 路由器或 NAS 上,通常通过订阅转换服务得到一份 YAML 文件,再放到对应目录。

  1. 在后台拿到原始订阅链接
  2. 使用订阅转换得到 Clash 配置
  3. 把配置文件放入 /etc 目录
  4. 重启 clash 守护进程
  5. 局域网设备网关指向路由器 IP
部署说明
EDGE · TV / 浏览器

电视端与浏览器插件

智能电视一般需要借助路由器侧代理,浏览器可使用 SwithyOmega 等插件做按需切换。

  1. 电视连接已开启代理的路由器
  2. 浏览器安装代理切换插件
  3. 导入同一份订阅配置
  4. 按域名设置自动切换规则
  5. 日常浏览即可走代理通道

FAQ · 05

FAQ 按主题分成四组:套餐与计费、设备与流量、节点与体验、技术与售后。点击问题可以展开答案。

光速云的订阅规则经常被混在一些零散的聊天记录里,这里把高频疑问整理成段落,希望能一次性说清楚。如果你找到的问题不在列表里,可以在底部联系栏留言。

FAQ 中提到的“套餐”“节点”“专线”等说法都来自本页前面的章节描述,术语如有冲突,以套餐列表与本节为准。

套餐与计费

套餐之间可以中途升降级吗?

可以。在订阅有效期内,进入后台的“我的套餐”页面选择升档或降档,差价会按剩余天数折算。升档立即生效,降档通常在下一计费周期开始时切换。

按月付和按年付的流量是分开算的吗?

不分开。无论按月还是按年付费,套餐对应的月流量额度是每个月重置的。按年付只是把 12 个月合并结算,流量仍按自然月刷新。

续费会自动扣款吗?

默认不开启自动续费。到期前系统会提醒,如未手动续费,服务会保留一小段宽限期,之后停机。建议在到期前 3 天处理。

设备与流量

“支持 3 台设备同时在线”是什么意思?

指的是同一时间可以有多少个客户端实例保持连接。比如手机、电脑、平板同时挂着,就算 3 台;再多开一台就会提示并发超限。

流量用完了会怎样?

当月流量耗尽后,客户端仍然可以连接,但会被路由到限速节点,普通浏览没问题,视频与下载会明显变慢。新一个月开始后恢复正常额度。

100GB / 300GB 够用吗?

粗略估算:在线标清视频约 1–2GB / 小时,高清 4K 可达 5GB 以上。仅日常浏览和偶尔看剧,100GB 通常足够;重度追剧建议直接上 300GB。

节点与体验

IPLC 专线和普通线路区别大吗?

IPLC 专线在跨境段走企业级通道,波动相对更小,适合对延迟敏感的游戏和远程办公。普通线路则用公共中转,高峰期可能有波动,但价格更低。

流媒体解锁是怎么实现的?

套餐内标注的“原生流媒体解锁”,指的是对应节点的出口 IP 被相应平台识别为本地住宅或商用段,可正常观看已订阅内容。具体可用清单随平台调整。

为什么有时候要手动切换节点?

跨境网络状况会随时间变化。当某个节点出现延迟升高或被目标网站限速时,切换到同区域另一个节点通常就能恢复,客户端测速页可以辅助判断。

技术与售后

订阅链接泄露了怎么办?

立刻在后台重置订阅链接,旧链接会失效。同时建议检查账号近期登录记录,如有异常设备,在“会话管理”里踢出。

工单一般多久回复?

旗舰版与团队版提供 7x24 优先工单支持,通常数小时内有初步响应;基础版在工作时段处理,首次回复一般在当天内。

支持哪些付款方式?

常见的方式包括在线支付与对公转账,具体可用渠道在下单页面会列出。团队版如果需要发票或合同,可以联系专属客户经理处理。
